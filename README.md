# استوديو التوقع والدرجة

موقع يصوّر فيه المدرس الطلاب وهم يقولون توقعهم لنتيجة الامتحان. الموقع يتعرف على الرقم من الكلام تلقائي، وبعد الامتحان تنضاف الدرجات (كتابة أو ملف إكسل)، ويطلع فيديو طولي واحد: التوقع يظهر مع صوت، الصورة تتجمد، والدرجة الحقيقية تطلع.

كل المقاطع والدرجات تبقى في متصفح المدرس على جهازه ولا تنرفع لأي مكان.
